# Contribuer à ShopFlow 
1. Partir de main à jour : git switch main puis git pull.
2. Créer une branche : git switch -c feature/mon-sujet.
3. Faire des commits atomiques avec des messages clairs.
4. Lancer mvn test avant chaque push : 42 tests réussis.
5. Pousser la branche et ouvrir une pull request vers main.
6. Fusionner seulement après la relecture d’un colègue.
